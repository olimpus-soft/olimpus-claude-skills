# Data Classes - Python 3.10+

Complete technical reference for dataclasses in Python. For decisions on when to use dataclass vs Pydantic vs TypedDict, consult the main skill (`/developer`).

## Fundamentals

Dataclasses eliminate boilerplate for classes that are primarily data. The `@dataclass` decorator automatically generates `__init__`, `__repr__`, `__eq__`, and other methods.

**When to use:**
- Domain classes (entities, value objects)
- Internal DTOs (without external validation)
- Structured configurations
- Lightweight alternative to Pydantic

**When NOT to use:**
- External data validation → Use Pydantic
- JSON/dict schema → Use TypedDict
- Just a named tuple → Use NamedTuple

## Basic Dataclass

### Definition
```python
from dataclasses import dataclass

@dataclass
class User:
    id: int
    name: str
    email: str
    active: bool = True

# Usage
user = User(id=1, name="Alice", email="alice@example.com")

print(user)  # User(id=1, name='Alice', email='alice@example.com', active=True)
print(user.name)  # Alice

# Automatic comparison
user2 = User(id=1, name="Alice", email="alice@example.com")
print(user == user2)  # True
```

### Generated Methods
```python
@dataclass
class Point:
    x: float
    y: float

# __init__ generated
p = Point(1.0, 2.0)

# __repr__ generated
print(p)  # Point(x=1.0, y=2.0)

# __eq__ generated
p2 = Point(1.0, 2.0)
print(p == p2)  # True

# __hash__ not generated by default (if mutable)
# To make hashable, use frozen=True
```

### Real-World Example

**Domain Models - E-commerce:**
```python
from dataclasses import dataclass
from datetime import datetime
from decimal import Decimal

@dataclass
class Product:
    id: str
    name: str
    price: Decimal
    stock: int
    created_at: datetime

@dataclass
class OrderItem:
    product_id: str
    quantity: int
    unit_price: Decimal

    @property
    def total(self) -> Decimal:
        return self.unit_price * self.quantity

@dataclass
class Order:
    id: str
    customer_id: str
    items: list[OrderItem]
    created_at: datetime

    @property
    def total(self) -> Decimal:
        return sum(item.total for item in self.items)

# Usage
item1 = OrderItem("prod-1", quantity=2, unit_price=Decimal("10.99"))
item2 = OrderItem("prod-2", quantity=1, unit_price=Decimal("5.50"))

order = Order(
    id="order-123",
    customer_id="user-456",
    items=[item1, item2],
    created_at=datetime.now()
)

print(f"Order total: ${order.total}")  # Order total: $27.48
```

## frozen=True - Immutability

### Definition

`frozen=True` makes instances immutable and hashable.
```python
from dataclasses import dataclass

@dataclass(frozen=True)
class Point:
    x: float
    y: float

p = Point(1.0, 2.0)
# p.x = 3.0  # FrozenInstanceError

# Now hashable
points_set = {Point(1.0, 2.0), Point(3.0, 4.0)}
```

### Real-World Example

**Value Objects (DDD):**
```python
from dataclasses import dataclass
from decimal import Decimal

@dataclass(frozen=True)
class Money:
    """Value object for money — always immutable."""
    amount: Decimal
    currency: str

    def __post_init__(self) -> None:
        if self.amount < 0:
            raise ValueError("Amount cannot be negative")
        if self.currency not in ("USD", "EUR", "BRL"):
            raise ValueError(f"Invalid currency: {self.currency}")

    def add(self, other: "Money") -> "Money":
        if self.currency != other.currency:
            raise ValueError("Cannot add different currencies")
        return Money(self.amount + other.amount, self.currency)

    def multiply(self, factor: int | float) -> "Money":
        return Money(self.amount * Decimal(str(factor)), self.currency)

# Usage
price = Money(Decimal("10.99"), "USD")
total = price.multiply(3)  # Creates new instance
print(total)  # Money(amount=Decimal('32.97'), currency='USD')

# Can use in dicts/sets
prices = {
    Money(Decimal("10.00"), "USD"): "Basic",
    Money(Decimal("20.00"), "USD"): "Premium"
}
```

**Coordinates and Geometry:**
```python
from dataclasses import dataclass
from math import sqrt

@dataclass(frozen=True)
class Point2D:
    x: float
    y: float

    def distance_to(self, other: "Point2D") -> float:
        dx = self.x - other.x
        dy = self.y - other.y
        return sqrt(dx**2 + dy**2)

    def translate(self, dx: float, dy: float) -> "Point2D":
        return Point2D(self.x + dx, self.y + dy)

@dataclass(frozen=True)
class Rectangle:
    top_left: Point2D
    bottom_right: Point2D

    @property
    def width(self) -> float:
        return self.bottom_right.x - self.top_left.x

    @property
    def height(self) -> float:
        return self.bottom_right.y - self.top_left.y

    @property
    def area(self) -> float:
        return self.width * self.height

# Immutable usage
p1 = Point2D(0.0, 0.0)
p2 = p1.translate(10.0, 5.0)  # New object
print(p2)  # Point2D(x=10.0, y=5.0)
```

### Established Use Cases

**Value Objects** (DDD):
- Money, Email, PhoneNumber
- Coordinates, Dimensions
- Always immutable by design

**Keys in Dicts/Sets**:
- Needs to be hashable
- Identity by value

**Thread-safe Data**:
- Share between threads without locks
- Immutability guarantees safety

## slots=True - Memory Optimization

### Definition

`slots=True` uses `__slots__` to reduce memory usage and increase attribute access speed.
```python
from dataclasses import dataclass

@dataclass(slots=True)
class Point:
    x: float
    y: float

# Without slots: ~152 bytes per instance
# With slots: ~64 bytes per instance (~58% savings)
```

### Memory Comparison
```python
import sys
from dataclasses import dataclass

@dataclass
class PointNoSlots:
    x: float
    y: float

@dataclass(slots=True)
class PointWithSlots:
    x: float
    y: float

p1 = PointNoSlots(1.0, 2.0)
p2 = PointWithSlots(1.0, 2.0)

print(sys.getsizeof(p1.__dict__))  # ~240 bytes (dict overhead)
print(sys.getsizeof(p2))           # ~64 bytes (no dict)
```

### Real-World Example

**High-Volume Data Processing:**
```python
from dataclasses import dataclass

@dataclass(frozen=True, slots=True)
class LogEntry:
    """Log entry — millions in memory."""
    timestamp: float
    level: str
    message: str
    source: str

# Process millions of logs
logs: list[LogEntry] = []
for line in read_large_log_file():
    logs.append(parse_log_line(line))

# With slots: ~40% less memory
# Important for large datasets
```

**Particle Simulation:**
```python
from dataclasses import dataclass

@dataclass(slots=True)
class Particle:
    """Particle in physics simulation."""
    x: float
    y: float
    z: float
    vx: float
    vy: float
    vz: float
    mass: float

# Simulate 1 million particles

    for _ in range(1_000_000)

```

### Established Use Cases

**Large Collections**:
- Millions of instances in memory
- Data processing, ML datasets

**Performance-Critical Code**:
- Game engines
- Simulations
- Real-time systems

**Restriction: Cannot add attributes dynamically**
```python

    x: float
    y: float

# p.z = 3.0  # AttributeError: 'Point' object has no attribute 'z'
```

## field() - Fine-Grained Control

### default_factory

For mutable default values:
```python
from dataclasses import dataclass, field

@dataclass
class User:
    name: str
    tags: list[str] = field(default_factory=list)  # Correct
    # tags: list[str] = []  # WRONG - shared between instances!

# Each instance has its own list
user1 = User("Alice")
user2 = User("Bob")

user1.tags.append("admin")
print(user1.tags)  # ["admin"]
print(user2.tags)  # [] - separate list
```

### init=False

Computed field, not accepted in `__init__`:
```python
from dataclasses import dataclass, field
from datetime import datetime

@dataclass
class Order:
    items: list[str]
    created_at: datetime = field(default_factory=datetime.now, init=False)

# created_at generated automatically
order = Order(items=["item1", "item2"])
print(order.created_at)  # Creation timestamp
```

### repr=False, compare=False

Controls method generation:
```python
from dataclasses import dataclass, field

@dataclass
class User:
    id: int
    name: str
    password_hash: str = field(repr=False)  # Not shown in repr
    internal_state: dict = field(default_factory=dict, compare=False)

user = User(id=1, name="Alice", password_hash="secret123")
print(user)  # User(id=1, name='Alice') - without password_hash
```

### Real-World Example

**Audit Trail:**
```python
from dataclasses import dataclass, field
from datetime import datetime
from uuid import uuid4

@dataclass
class AuditedEntity:
    """Entity with audit metadata."""
    name: str
    data: dict

    # Auto-generated metadata
    id: str = field(default_factory=lambda: str(uuid4()), init=False)
    created_at: datetime = field(default_factory=datetime.now, init=False)
    updated_at: datetime = field(default_factory=datetime.now, init=False)
    version: int = field(default=1, init=False)

    # Don't compare audit metadata
    _metadata: dict = field(
        default_factory=dict,
        compare=False,
        repr=False
    )

# Create entity
entity = AuditedEntity(name="Product", data={"price": 10.99})
print(entity.id)  # Generated UUID
print(entity.created_at)  # Current timestamp
```

**Configuration with Validation:**
```python
from dataclasses import dataclass, field
from pathlib import Path

@dataclass
class ServerConfig:
    host: str
    port: int
    workers: int = 4

    # Derived fields
    base_url: str = field(init=False)
    log_dir: Path = field(default_factory=lambda: Path("/var/log"), init=False)

    def __post_init__(self) -> None:
        # Validation
        if not 1024 <= self.port <= 65535:
            raise ValueError(f"Invalid port: {self.port}")
        if self.workers < 1:
            raise ValueError("Workers must be >= 1")

        # Calculate derived fields
        self.base_url = f"http://{self.host}:{self.port}"

config = ServerConfig(host="localhost", port=8080)
print(config.base_url)  # http://localhost:8080
```

## __post_init__ - Validation and Processing

### Definition

`__post_init__` runs after `__init__`, allowing validation and processing.
```python
from dataclasses import dataclass

@dataclass
class Rectangle:
    width: float
    height: float

    def __post_init__(self) -> None:
        if self.width <= 0:
            raise ValueError("Width must be positive")
        if self.height <= 0:
            raise ValueError("Height must be positive")

# Automatic validation
rect = Rectangle(10.0, 5.0)  # OK
# rect = Rectangle(-10.0, 5.0)  # ValueError
```

### Real-World Example

**Email Value Object:**
```python
from dataclasses import dataclass
import re

@dataclass(frozen=True)
class Email:
    """Validated and normalized email."""
    address: str

    def __post_init__(self) -> None:
        # Validation
        if "@" not in self.address:
            raise ValueError(f"Invalid email: {self.address}")

        pattern = r"^[\w\.-]+@[\w\.-]+\.\w+$"
        if not re.match(pattern, self.address):
            raise ValueError(f"Invalid email format: {self.address}")

        # Normalization (frozen requires object.__setattr__)
        normalized = self.address.lower().strip()
        object.__setattr__(self, "address", normalized)

    @property
    def domain(self) -> str:
        return self.address.split("@")[1]

# Usage
email = Email("  Alice@EXAMPLE.com  ")
print(email.address)  # alice@example.com (normalized)
print(email.domain)   # example.com
```

**Computed Fields:**
```python
from dataclasses import dataclass, field

@dataclass
class Product:
    name: str
    price_cents: int

    # Computed field
    price_formatted: str = field(init=False)

    def __post_init__(self) -> None:
        dollars = self.price_cents / 100
        self.price_formatted = f"${dollars:.2f}"

product = Product(name="Widget", price_cents=1299)
print(product.price_formatted)  # $12.99
```

**Normalization and Defaults:**
```python
from dataclasses import dataclass
from typing import Optional

@dataclass
class SearchQuery:
    term: str
    page: int = 1
    limit: int = 10

    def __post_init__(self) -> None:
        # Normalization
        self.term = self.term.strip().lower()

        # Validation
        if not self.term:
            raise ValueError("Search term cannot be empty")

        # Adjustments
        if self.page < 1:
            self.page = 1
        if self.limit < 1:
            self.limit = 10
        if self.limit > 100:
            self.limit = 100

query = SearchQuery("  Python  ", page=0, limit=500)
print(query.term)   # python
print(query.page)   # 1
print(query.limit)  # 100
```

## Inheritance

### Definition

Dataclasses support inheritance, with base class fields first.
```python
from dataclasses import dataclass

@dataclass
class Animal:
    name: str
    age: int

@dataclass
class Dog(Animal):
    breed: str

# Order: name, age, breed
dog = Dog(name="Rex", age=3, breed="Labrador")
print(dog)  # Dog(name='Rex', age=3, breed='Labrador')
```

### Real-World Example

**Domain Entities:**
```python
from dataclasses import dataclass
from datetime import datetime
from uuid import uuid4

@dataclass
class BaseEntity:
    """Base entity with common fields."""
    id: str
    created_at: datetime
    updated_at: datetime

@dataclass
class User(BaseEntity):
    """System user."""
    email: str
    name: str
    is_active: bool = True

@dataclass
class Product(BaseEntity):
    """Catalog product."""
    name: str
    price: float
    stock: int

# Create entities with base fields
user = User(
    id=str(uuid4()),
    created_at=datetime.now(),
    updated_at=datetime.now(),
    email="alice@example.com",
    name="Alice"
)
```

**Event Hierarchy:**
```python
from dataclasses import dataclass
from datetime import datetime
from enum import Enum

class EventType(Enum):
    USER_CREATED = "user.created"
    USER_UPDATED = "user.updated"
    ORDER_PLACED = "order.placed"

@dataclass
class BaseEvent:
    """Base event."""
    event_id: str
    event_type: EventType
    timestamp: datetime

@dataclass
class UserCreatedEvent(BaseEvent):
    """User creation event."""
    user_id: str
    email: str
    name: str

@dataclass
class OrderPlacedEvent(BaseEvent):
    """Order placed event."""
    order_id: str
    user_id: str
    total_amount: float
    items_count: int

# Polymorphism
def handle_event(event: BaseEvent) -> None:
    if isinstance(event, UserCreatedEvent):
        send_welcome_email(event.user_id, event.email)
    elif isinstance(event, OrderPlacedEvent):
        process_order(event.order_id)
```

## Comparison with Alternatives

### Dataclass vs NamedTuple
```python
from dataclasses import dataclass
from typing import NamedTuple

# NamedTuple - immutable, inherits from tuple
class PointTuple(NamedTuple):
    x: float
    y: float

# Dataclass - mutable by default, more flexible
@dataclass
class PointClass:
    x: float
    y: float

# Frozen dataclass - similar to NamedTuple
@dataclass(frozen=True)
class PointFrozen:
    x: float
    y: float
```

**When to use each:**

| Aspect | NamedTuple | Dataclass | Dataclass(frozen=True) |
|--------|------------|-----------|------------------------|
| Mutability | Immutable | Mutable | Immutable |
| Methods | Can add | Can add | Can add |
| Inheritance | Limited | Full | Full |
| Performance | Faster | Normal | Normal |
| Memory | Smaller | Larger | Larger |
| Use when | Simple tuples | Complex objects | Value objects |

### Dataclass vs TypedDict
```python
from dataclasses import dataclass
from typing import TypedDict

# TypedDict - just a type hint for dict
class UserDict(TypedDict):
    id: int
    name: str

# Dataclass - real class
@dataclass
class UserClass:
    id: int
    name: str

# TypedDict is just a dict at runtime
user_dict: UserDict = {"id": 1, "name": "Alice"}
print(type(user_dict))  # <class 'dict'>

# Dataclass is its own class
user_class = UserClass(id=1, name="Alice")
print(type(user_class))  # <class '__main__.UserClass'>
```

**When to use each:**

| Use Case | TypedDict | Dataclass |
|----------|-----------|-----------|
| JSON/API payloads | ✅ Ideal | ❌ Overhead |
| Domain objects | ❌ No methods | ✅ Ideal |
| Database rows | ✅ Lightweight | Depends |
| Config files | ✅ Simple | ❌ Complex |

### Dataclass vs Pydantic
```python
from dataclasses import dataclass
from pydantic import BaseModel, field_validator

# Dataclass - no runtime validation
@dataclass
class UserDataclass:
    id: int
    email: str

# Pydantic - automatic validation
class UserPydantic(BaseModel):
    id: int
    email: str

    @field_validator("email")
    @classmethod
    def validate_email(cls, v: str) -> str:
        if "@" not in v:
            raise ValueError("Invalid email")
        return v

# Dataclass accepts anything (type checker warns)
user_dc = UserDataclass(id=1, email="invalid")  # OK at runtime

# Pydantic validates
# user_p = UserPydantic(id=1, email="invalid")  # ValidationError
```

**When to use each:**

| Use Case | Dataclass | Pydantic |
|----------|-----------|----------|
| Internal data | ✅ Lightweight | ❌ Overhead |
| External API | ❌ No validation | ✅ Ideal |
| Production config | ❌ No validation | ✅ Ideal |
| Domain models | ✅ Simple | Depends |
| Performance-critical | ✅ Faster | ❌ Slower |

## Serialization

### asdict() and astuple()
```python
from dataclasses import dataclass, asdict, astuple

@dataclass
class User:
    id: int
    name: str
    email: str

user = User(id=1, name="Alice", email="alice@example.com")

# Convert to dict
user_dict = asdict(user)
print(user_dict)  # {'id': 1, 'name': 'Alice', 'email': 'alice@example.com'}

# Convert to tuple
user_tuple = astuple(user)
print(user_tuple)  # (1, 'Alice', 'alice@example.com')
```

### Nested Dataclasses
```python
from dataclasses import dataclass, asdict

@dataclass
class Address:
    street: str
    city: str
    country: str

@dataclass
class Person:
    name: str
    address: Address

person = Person(
    name="Alice",
    address=Address(street="123 Main St", city="NYC", country="USA")
)

# asdict is recursive
person_dict = asdict(person)
print(person_dict)
# {
#     'name': 'Alice',
#     'address': {'street': '123 Main St', 'city': 'NYC', 'country': 'USA'}
# }
```

### Real-World Example

**JSON API Response:**
```python
from dataclasses import dataclass, asdict
from datetime import datetime
import json

@dataclass
class Product:
    id: str
    name: str
    price: float
    created_at: datetime

def serialize_product(product: Product) -> str:
    """Serialize product to JSON."""
    data = asdict(product)
    # Convert datetime to ISO string
    data["created_at"] = product.created_at.isoformat()
    return json.dumps(data)

product = Product(
    id="prod-123",
    name="Widget",
    price=19.99,
    created_at=datetime.now()
)

json_str = serialize_product(product)
print(json_str)  # {"id": "prod-123", "name": "Widget", ...}
```

## Best Practices

✅ **Use frozen=True for value objects**
```python
@dataclass(frozen=True)
class Email:
    address: str
```

✅ **Use slots=True for large collections**
```python
@dataclass(slots=True)
class Particle:
    x: float
    y: float
    z: float
```

✅ **Use default_factory for mutables**
```python
@dataclass
class User:
    tags: list[str] = field(default_factory=list)
```

✅ **Validate in __post_init__**
```python
def __post_init__(self) -> None:
    if self.age < 0:
        raise ValueError("Age cannot be negative")
```

❌ **Don't use [] as default**
```python
# WRONG
@dataclass
class User:
    tags: list[str] = []  # Shared!

# CORRECT
@dataclass
class User:
    tags: list[str] = field(default_factory=list)
```
